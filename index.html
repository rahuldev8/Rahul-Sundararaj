CacheForge

More Details

CacheForge – In-Memory Key-Value Store

    CacheForge is a Java-based in-memory key-value store inspired by Redis, built to explore low-level networking, TCP communication, protocol handling, and concurrent client processing.

    Features

  • TCP Server Implementation - Built a TCP server using Java's ServerSocket API to accept and manage client connections.

  • RESP Protocol - Implemented the Redis Serialization Protocol (RESP) for client-server communication and command processing.

  • Key-Value Operations - Implemented core operations for storing and retrieving data in an in-memory key-value store.

  • Concurrent Client Handling - Implemented concurrent client handling to support multiple client connections.

  • Key Expiration - Implemented key expiration to manage the lifecycle of stored entries.

    • Role & Responsibilities

  • Designed and developed the in-memory key-value store using Java socket programming.

  • Implemented TCP communication and RESP-based command processing.

  • Developed core data operations, concurrent client handling, and key expiration functionality.

    • Tech Stack Used
    Java, Socket Programming, TCP, RESP Protocol
